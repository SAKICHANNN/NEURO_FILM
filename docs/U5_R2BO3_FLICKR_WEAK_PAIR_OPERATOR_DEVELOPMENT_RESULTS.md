# U5.R2BO3 weak-pair global operator development

The scene-held development experiment closes a single average operator. Two
runs are byte-identical at `fcd9a3d8...7b82430`; the 12 held confirmation
pairs remain pixel-unread.

The 12-parameter monotone-curve/positive-matrix operator beats the 6-parameter
basic control on 67.5% of development scenes and lowers mean RMSE from 0.1332
to 0.1250, but its frozen median-improvement gate fails at **4.03% < 5%**.
The 14-parameter triangular operator also fails (1.13% median improvement,
57.5% wins, and negative Nikon/Ricoh family median). Thresholds are unchanged.

This closes the one-average-operator route without a capacity rescue. A
mechanism-distinct next question remains legitimate: using the same bounded
12-parameter operator per development scene, does an evaluator Oracle prove
that a hard case bank has enough value to justify source-only retrieval?
