# U6.P2Z Emulating Emulsion author-package audit results

The exact primary-author audit closes before reproduction. The
[2025 project page](https://musicofmusix.github.io/siggraphposters25),
[DOI record](https://doi.org/10.1145/3721250.3743014), author-hosted abstract,
poster and eight-page full paper establish a valuable paired compact baseline:
one Velvia 100 roll, 33 captures, 4,620 total chart-patch pairs, 3,168 unique
rows and a 30-parameter two-matrix/three-sigmoid equation family.

The full paper resolves the abstract's patch-count wording: the chart has 140
total positions but 96 unique patches per shot. This is not treated as a
publication contradiction. The public author surface nevertheless contains no
explicit algorithm repository, software licence, runnable implementation,
numeric fitted parameter bundle or complete paired-row table. It also lacks the
rights and complete capture/process/scan/split lineage required by the frozen
reproduction gate. The project-page statement that provided source code can
operate in ProPhoto RGB is retained as a claim, not evidence that such a
package is publicly available.

Two formal reports are byte-identical at SHA-256
`f0f5d6e8...17fbe`; stable evidence ID `e9609030...e469`. No operator fit,
render or visual review occurred. Emulating Emulsion remains the current best
paired compact equation-family and capture-design baseline, but this public
package cannot support clean-room reproduction, transferable stock truth or a
complete physical-emulsion claim. The next leaf audits Kodak Digital LAD as an
official machine-readable recorder/print calibration anchor.
