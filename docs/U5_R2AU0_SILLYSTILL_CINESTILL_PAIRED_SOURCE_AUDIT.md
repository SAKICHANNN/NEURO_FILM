# U5.R2AU0 — Sillystill CineStill paired-source audit

The source is methodologically relevant but not executable as a project data
leaf.

The paper reports 41 sequential same-scene Sony Alpha 7 / Nikon F3
CineStill-800T pairs, tripod capture, and spatial plus luminance alignment.
That is much closer to the missing controlled evidence than community film
photos or author-rendered display proxies.

The official repository was checked at commit
`b1ebdb971207b403b7126b759c1d30d30954a722`. Its 221-entry tree has no dataset
directory, no release, and no root licence. The README still labels both the
Zenodo and Hugging Face dataset links “Not yet available”. It contains only one
example digital ARW and one corresponding film JPEG. The open dataset-release
issue has no author response.

The example pair is not a substitute for the claimed dataset: reuse rights,
scanner/profile lineage, roll/process groups, colour-state mapping and an
independent held group are all absent. It therefore cannot authorize fitting,
training, visual promotion or a CineStill stock claim.

Reopen only if an author-controlled release supplies the complete immutable
pair set, explicit reusable rights and sufficient capture/process/scanner
lineage for group-held evaluation. Until then this is a precise data gap, not a
negative result about paired explicit operators.
