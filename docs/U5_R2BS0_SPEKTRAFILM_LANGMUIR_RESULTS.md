# U5.R2BS0 Spektrafilm Langmuir ablation results

The same-revision external ablation passes every frozen automatic gate. Two
complete Python 3.13.14 runs are exact. Relative to the linear donor, the
Langmuir arm has median effect `2.8774` Delta E76 while retaining median style
`7.4825` and non-basic residual `6.8361`. Worst new hard boundary is zero,
worst isolated red speckle is `0.03532%`, and gradient/chroma-HF ratios are
`1.0359/0.9520`.

Only after that pass, one blinded autonomous visual review found no severe
artifact in any arm. Langmuir ranked above the same-revision linear donor on
6/9 photographs and above AO6 on 7/9. No preference threshold had been
pre-registered, so these counts are descriptive rather than promotion proof.

Decision: retain the amplitude-matched non-spatial Langmuir donor as external
development mechanism evidence and open one independent bounded implementation
pilot. The external GPL/CC-BY-SA implementation and profiles are not copied or
integrated. This is not a measured DIR response, stock calibration, identified
digital-to-film operator, population preference, training target, or product
promotion.
