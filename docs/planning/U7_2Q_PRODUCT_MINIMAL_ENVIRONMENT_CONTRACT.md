# U7.2Q Product Minimal Environment Contract

## Question

Can the existing deterministic `film-inspired / Look Approximation` product
CLI run from a fresh Windows Python 3.12 environment without installing the
project's CUDA, training, diffusion, evaluation or document-research stack?

U7.2P proved that an already provisioned environment does not import the
unselected research graph. It did not provide or test a product dependency
manifest. The repository currently exposes only the full research
`requirements.txt` and the corresponding macOS research environment.

## Frozen scope

1. Add one pinned `requirements-product.txt` for the current private Windows
   product path. It may contain only packages needed by the existing CLI,
   raster/RAW ingress, deterministic colour/effects path, recipe and output
   publication code.
2. Build two independent Python 3.12 virtual environments under the
   repository-relative `tmp/` junction. Install the exact manifest with
   binary wheels only and run `pip check`.
3. In each environment run the unchanged U7.2P formal audit. Catalog
   discovery, all three product looks at amounts `0`, `0.5`, `1`, normalized
   recipes, the full image/recipe/layers/metrics bundle, conflict controls and
   analytic-branch preservation must remain exact.
4. Record the installed distribution/version inventory. Every direct and
   transitive runtime distribution must be pinned by the manifest; forbidden
   research/ML distributions and imports must be absent.
5. Remove both owned environments and all owned audit output after evidence
   capture. Source files and pre-existing destinations remain immutable.

## Frozen gates

- two independent fresh environments are created with Python 3.12;
- binary-only installation and `pip check` succeed in both;
- installed distribution/version inventories are identical and completely
  covered by the manifest;
- no forbidden research/ML distribution is installed;
- the two nested U7.2P reports are byte-identical to each other and retain all
  twelve passing U7.2P gates;
- all product outputs, normalized recipes and auxiliary bundle identities
  remain exact to U7.2O/U7.2P;
- the analytic research route remains available only when explicitly selected;
- owned environment, report and media residue is zero.

Any failure closes this exact manifest and environment. Do not add a missing
package after a product execution has begun, relax versions, switch Python,
drop RAW/raster support, remove controls or alter renderer code in this leaf.

## Claim ceiling

A pass proves only a private Windows Python 3.12 product-runtime dependency
manifest and fresh-environment execution for the existing deterministic Look
Approximation CLI. It is not an installer, wheel, executable, signed package,
public API, release, macOS/Linux parity, arbitrary-input compatibility,
calibrated stock response, physical-film reproduction or product-value result.
AO6 remains only a Velvia 50 display-proxy baseline.
