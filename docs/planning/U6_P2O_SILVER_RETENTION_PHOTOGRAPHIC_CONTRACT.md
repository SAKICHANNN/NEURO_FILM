# U6.P2O silver-retention photographic contract

P2O inserts the exact P2N neutral-silver density between dye diffusion and the
existing print interpretation in the retained P7F chain. The baseline is the
unchanged gauged 4000-dpi P7F physical chain; both arms receive the same AO6
colour operator. No photograph trains or tunes the process.

Because the print operator has a frozen density domain, P2O scales only the
requested silver residual along its own direction by the analytical
per-pixel headroom. It never clips density. The automatic audit requires a
visible and matched-basic-nontrivial change, broad population support,
controlled luma/chroma behavior, no new boundaries and no isolated
excursions. Visual review is forbidden unless every automatic gate passes.

This remains a generic Look Approximation on display-derived pseudo-exposure.
It cannot identify or calibrate bleach bypass, silver retention, stock,
processing, or scanner behavior.
