# U5.R2B fixed global operator frontier contract

Date frozen: 2026-07-23

Node: `ULT > U5 > U5.R2 > U5.R2B`

Status: **frozen before the U5.R2B full-set render or metric result**

## Research question

Among the already evidence-eligible, deterministic, global colour-only
policies, is there a fixed challenger that is visibly stronger and more
non-basic than safe-rich while surviving the independent severe-artifact veto?

This is a B0 development-frontier experiment. It does not estimate a real
digital-to-film operator, identify a stock response, complete a hidden
confirmatory evaluation or establish population preference.

  existing U4, owner-anchor, RF2.C0 and ID11 evidence in A0.
- U5.R2A provides a replayable constrained global-operator representation and
  proves by counterexample that numerical constraints are not semantic safety.
- Current real-film stock pixels remain unidentified and closed to fitting,
  training and LSM.
- The frozen local A0 set contains nine provisional gold and 32 stress inputs
  at SHA-256
  `de78bb8ee3db76ae217bdf19dfc043cfcfd8bae1f55797f58f9bb0ed3526cc15`.

## Frozen automatic screen

Metrics use a deterministic uniform grid with at most 65,536 pixels per image.
For every candidate/image report:

- median CIELAB Delta E76 from input;
- median residual Delta E76 after the frozen RF2.S0 implementation's joint
  EV, white-balance, contrast and saturation affine diagnostic;
- new hard clipping fraction, with endpoint epsilon `0.5/255`;
- output bounds and finite state.

A primary candidate is an automatic survivor only if:

- all 41 outputs are complete, finite and decode-clean;
- gold median style Delta E76 is at least `7.0`;
- gold median matched-basic residual Delta E76 is at least `4.9`;
- worst gold new hard clipping is at most `0.5%`;
- worst stress new hard clipping is reported and not used to hide a gold
  failure.

These floors are inherited from the pre-existing RF2.S0/RF2.C0 anchor-derived
screen. They measure salience/non-basic structure, not film authenticity or
appeal.

### Pre-result metric-label correction

Before the first U5.R2B metric report was generated, source inspection found
that the inherited `style_and_basic_residual()` implementation calls
`fit_joint_basic_adjustment()`, whose five fitted parameters are EV, two
white-balance coordinates, contrast and saturation. It does **not** fit a
separate global-luma curve. The original prose and config label incorrectly
included `global-luma`, although the inherited numerical thresholds were
derived with the affine implementation. This correction changes only the
metric label and claim boundary; it preserves the implementation, candidate
bank and every frozen numeric gate. Adding a new luma-curve fitter now would
change the diagnostic and invalidate the inherited thresholds.

## Visual gate

Only automatic survivors proceed. Build three deterministically shuffled
anonymous gold contact-sheet rounds containing input, safe-rich and each
survivor. The primary review order is:

1. severe glitch/artifact;
2. target-look salience relative to safe-rich and owner anchors;
3. descriptive appeal/tone/palette notes.

All nine gold images require full-resolution inspection for face/skin,
text/logo, fine texture, smooth gradients, saturated objects, highlights and
deep shadows. ID11 explicitly regresses red speckle/posterization for
`09/53/55/56`. One confirmed severe failure vetoes that candidate. Ambiguous
cases do not promote.

Autonomous visual evidence is not owner, human-panel or population preference.
The historical user preference list remains qualitative evidence and is not
silently converted into numeric labels.

## Selection and branches

Among automatic and visual survivors:

- retain the strongest fixed global B0 challenger only when it is visibly more
  stylized/non-basic than safe-rich and has zero confirmed severe gold
  failures;
- if multiple survivors are visually tied, choose the simpler/lower-strength
  fixed recipe;
- if every strong candidate fails safety, retain safe-rich as the product
  fallback and record the frontier gap;
- if only a bland/basic candidate survives, do not call the frontier solved;
- stress failures are reported by candidate and type, never averaged away.

A retained B0 challenger does not become the production default. U5.R2C still
requires a complete fixed-bank, disjoint-panel empirical-ceiling policy before
adaptive routing can open.

- integrate a challenger into production profiles/defaults;
- claim calibrated stock response, authenticity, semantic safety or population
  preference;
- weaken the severe-artifact veto.

screen, complete survivor visual evidence, branch decision, focused and full
CPU verification, claim ceiling and propagation to all active authorities.
