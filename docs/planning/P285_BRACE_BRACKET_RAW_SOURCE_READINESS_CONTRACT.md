# P285 BRACE bracketed-RAW source readiness contract

## Question

Does the latest official 2026 BRACE release provide a rights-compatible,
exactly inventoried and independently executable bracketed-RAW physical
observation that can open a separate prospective capture-time experiment?

## Frozen official sources

- Repository: `ZZH-qwq/BRACE`, commit
  `c17763bdab166da11cff2eb42d7f6df51d0105a2`, tree
  `63b5906181d31e3141db8585cc8bb5d4f5dbfccf`.
- Commit-pinned recursive Git tree and `README.md` only.
- Paper identity: arXiv `2606.29845`, as bound by the official README.
- The paper-level observation is materially different from prior after-only
  matching: bracketed RAW frames are produced by automated multi-exposure
  capture, and the model fuses information across exposures.

Only bounded GitHub API/raw responses may be requested. Repository cloning,
figure blobs, datasets, archives, manifests, RAW/JPEG images, checkpoints,
pixels, training and inference are forbidden in P285.

## Frozen readiness gates

All gates must pass simultaneously:

1. repository commit/tree and README identity are exact;
2. the official README identifies bracketed RAW and automated multi-exposure
   capture as a materially new physical observation;
3. the executable source has explicit commercial-compatible rights;
4. every required dataset subset has explicit commercial-compatible rights;
5. an executable installation and inference path is published;
6. an exact public dataset/archive inventory and checksums are published;
7. an exact public model/checkpoint locator and checksum are published;
8. official group identities or splits can support disjoint development and
   confirmation;
9. two fresh forward/reverse reports are byte-identical.

Repository visibility and a paper statement that data/code are available do
not grant rights or substitute for concrete released assets. A README badge
pointing back to the repository is not a dataset locator.

## Stop rule and claim ceiling

Failure of any gate yields
`NOT_READY_BRACE_RELEASE_AND_RIGHTS_GAP_NOT_SCIENTIFIC_RESULT`.
It authorizes no clone, figure/data/model request, pixel read, training,
inference, mirror use, rights inference, candidate-3 consumption or product
mapping.

A complete pass could open only a separately preregistered payload-integrity
and physical-observation preflight. P285 cannot establish restoration quality,
arbitrary RAW support, a shared operator, A1/A4/A5, package/schema/capability
or product admission.
