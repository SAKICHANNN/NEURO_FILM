Date: 2026-08-20

This leaf changes the identifying information source, not operator capacity.
Each fit scene supplies an original plus its already-frozen professional winner
render. Their same-content relation fits one safe 12D logit-affine effect
label. A standardized ridge then predicts that label from the winner
after-reference alone.

For all 24 calibration scenes, reference descriptors and candidate/global/
permuted predictions are materialized and hash-frozen before the first
calibration original is read. The original is evaluation input only; Build
never reads it. A scene-cyclic parameter-label model and a global mean operator
test content shortcut and aggregate-prior explanations. Per-scene oracle fits
are diagnostic only after the prediction freeze.

Any absolute, global-relative, permutation-relative, tail, salience or safety
gate failure closes the exact descriptor/ridge/operator family before sealed
member acquisition. No same-cohort feature, alpha, bound, dose, resize or gate
rescue is allowed. A pass opens only separately frozen sealed confirmation.
