# U5.R2BK23 — FiveK content-cell appearance control

BK23 is a real-raster method control for the synthetic BK22 mechanism. It does
not add a film dataset and does not reopen FilmSet output-only recovery.

The existing rights-audited FiveK freeze supplies 64 development and 64
disjoint confirmation photographs edited by Expert C. Exact photograph
identity is the external, colour-independent content cell. The unchanged BK22
two-objective O0 capacity sees only pooled development marginals; target row
order is destroyed and paired pixel coordinates are never used. Exact pair
identity is exposed only to confirmation scoring.

The confirmation target cells are evaluated twice:

1. against their observed source photograph identity;
2. after a fixed 17-cell cyclic permutation with the identical pooled target
   multiset.

One whole bounded operator may be selected only if every valid confirmation
cell improves by at least the frozen amount and the permuted control returns
identity. A valid-view fallback is a formal `K=1/identity` outcome, not an
experiment failure. A permuted-view hard candidate closes the mechanism as
unsafe. Lineage, licence, cube, Jacobian, inverse and replay failures veto the
experiment.
