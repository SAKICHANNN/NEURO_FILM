# Roll2Film CT1/E0 Affine Identifiability Foundation

> Date: 2026-07-13
> Scope: data-independent, CPU-only, known-truth synthetic evidence
> Decision: **restricted pass; CT3 remains in progress**

## Question

Can multiple independent target frames generated by one shared explicit colour
operator make that operator more identifiable than a single frame, without
using source/target pairs during estimation?

This first falsification leaf deliberately uses the smallest identifiable
operator family: an orientation-preserving affine transform in linear sRGB.
It does not test real film, named stocks, scanner/process separation, monotone
curves, LUT residuals or learned set inference.

## Frozen contract

- operator schema: `roll2film.affine.v1`;
- transform: `y = A x + b`, with positive determinant and no implicit clipping;
- exact inverse and JSON round-trip;
- estimator input: an independent neutral-prior sample and an unordered tuple
  of target frames;
- forbidden estimator input: paired source frames or the true parameters;
- identification assumption: the shared matrix is symmetric positive definite,
  which selects the unique Gaussian optimal-transport covariance map;
- hostile control: combine frames produced by two different operators under one
  false group label;
- group sizes: `1/2/4/8/16/32`, 48 replicates, 128 pixels per frame;
- primary metric: holdout RGB RMSE against the known operator on independent
  neutral samples.

The complete frozen configuration is `configs/roll2film_e0.json`. The ignored
raw report is written to `outputs/roll2film/e0/report.json`.

## Results

### Primary, no nuisance

| Frames | Correct-group RMSE | Mixed-operator RMSE | Mean style ratio |
|---:|---:|---:|---:|
| 1 | 0.017172 | 0.017172 | 1.401 |
| 2 | 0.011780 | 0.064095 | 1.230 |
| 4 | 0.008901 | 0.063552 | 1.142 |
| 8 | 0.006928 | 0.064121 | 1.117 |
| 16 | 0.005546 | 0.063517 | 1.065 |
| 32 | 0.004224 | 0.064019 | 1.039 |

The 32-frame correct group reduces holdout error by 75.4% relative to one
frame and is 93.4% lower than the 32-frame mixed-operator control. The fitted
style magnitude approaches the known transform rather than collapsing toward
identity.

### Mild nuisance stress

The stress condition adds per-frame log-exposure variation (`sigma=0.025`),
scene-mean shifts (`sigma=0.005`) and sensor noise (`sigma=0.002`), with a
simple per-frame luminance normalization. Correct-group RMSE falls from
0.021609 at one frame to 0.005464 at 32 frames; the mixed-operator control is
0.070120 at 32 frames. This is a diagnostic pass under a deliberately mild
nuisance model.

## Interpretation and gate

This result establishes only that the implementation can recover a restricted
known SPD affine operator from increasing unpaired group evidence and that an
incorrect mixed group does not mimic the same convergence. It validates the
CT1 test harness and keeps the Roll2Film hypothesis alive.

It does **not** complete CT3 or authorize data acquisition. Before the CT3
gate can pass, the same framework must cover:

1. independently controlled colour-support breadth;
2. stronger exposure/WB and scene-composition nuisance;
3. monotone curve and smooth LUT-residual truth families;
4. flexible-nuisance controls that could absorb the shared operator;
5. uncertainty and unsupported-colour support shrinkage;
6. a dedicated nearest-work/novelty check for grouped operator identification.

If gains disappear outside the SPD affine case, the claim must shrink to that
case or the Roll2Film method route must stop. FilmSet and BlueNeg remain
approval-gated and were not downloaded.
