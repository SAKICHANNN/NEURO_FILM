## 核心原理

```
输入图 → VAE编码 → 加噪(控量) → 带胶片LoRA降噪 → VAE解码 → 胶片输出
                ↑ t=0.4-0.5 控内容保真
                ↑ LoRA + Prompt 控胶片风格
```

**strength 参数 = 内容保真度控制器**：
- 0.3 = 几乎不动，轻胶色调
- 0.45 = 内容保留 + 明显胶片感 ← 推荐
- 0.6 = 强胶片，小细节可能变
- 1.0 = 纯文生图，内容全丢
