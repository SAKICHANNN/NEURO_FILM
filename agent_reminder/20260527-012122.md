## Important Project Conclusions From This Chat

1. The IP2P fine-tune direction produced severe painterly/smeared artifacts and should not be treated as the current usable film simulation path.
2. SDXL LoRA + SDEdit was validated but not promoted:
   - Low strength showed almost no visible change.
   - Higher strength caused semantic/content rewrite.
   - This was judged unsafe for content-preserving film translation.
3. The current best practical path is the deterministic color baseline:
   - Lab color-stat transfer from film-domain stats.
   - Optional grain, currently disabled for artifact-sensitive previews.
   - Content-safe compared with diffusion.
4. The user observed artifacts and color banding in earlier Velvia preview batches. The likely causes were too much strength, gamut clipping, and JPEG compression/overdrive on saturated colors.
5. For Velvia 50 previews, the best current softer setting is:
   - `strength=0.50`
   - `luma_strength=0.25`
   - `grain=0`
   - `gamut_safe=true`
   - `output_margin=4`
   - Save final `after` and pair/contact previews as PNG to avoid JPEG introducing fake 0/255 boundary hits.

Added a gamut-safe path:

- New helper functions:
  - `lab_to_linear_srgb`
  - `linear_to_srgb`
  - `in_srgb_gamut`

- `style_transfer(...)` now accepts `gamut_safe: bool`.
- When `gamut_safe=True`, it binary-searches from source Lab to target Lab so the transformed color stays inside displayable sRGB gamut instead of relying on hard clipping.
- Important caveat: if `grain > 0`, grain still uses `np.clip`; for "no clip" previews use `grain=0`.

### `scripts/make_rawpixls_velvia_preview.py`

New repeatable preview generator:

- Pulls candidate RAW files from `https://raw.pixls.us/json/getrepository.php`
- Filters for:
  - known digital camera makes,
  - RAW extensions,
  - CC0/Public Domain license,
  - non-monochrome terms,
  - max file size default 26 MB.
- Uses rawpy to render RAW with camera white balance.
- Applies the Velvia 50 deterministic color baseline.
- Generates:
  - neutral input previews,
  - PNG after images,
  - PNG left/right before-after pairs,
  - PNG contact sheet,
  - `manifest.csv`,

## Bugs/Pitfalls Discovered

1. raw.pixls.us links contain spaces and special characters. Need URL quoting of the path.
2. raw.pixls.us filenames include characters invalid on Windows paths, such as `:` in `(3:2)`. Use safe slugs for local cache files.
3. Windows console/logging can fail on unusual Unicode characters. The preview script uses ASCII-safe logging.
4. JPEG can reintroduce 0/255 boundary values via compression even after output margin protection. Use PNG for final after/pair/contact images.
5. `gamut_safe` avoids Lab-to-sRGB hard clipping, but very high style strength can still visually crush shadows or highlights. For Velvia 50 preview, `s=0.50` is currently safer than `s=0.58` or `s=0.72`.
